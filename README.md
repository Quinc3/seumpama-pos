# Seumpama POS

Web-based Point of Sale, Inventory Management, and Stock Forecasting
for Coffee Shop Seumpama Bunga — Tigaraksa, Kabupaten Tangerang, Banten.

## Stack

- Backend: Laravel 12 (Blade, Tailwind CSS, Alpine.js)
- ML Service: Python 3.12 + Keras
- Database: MariaDB (MySQL-compatible)
- Weather: Open-Meteo

## Structure

- `laravel-app/` — Laravel application (Phase 1)
- `python-ann-service/` — Python ANN service (Phase 1)
- `docs/` — Project planning and specifications
- `ENVIRONMENT_AUDIT.md` — Verified development environment

## Status

Phase 0 — Planning. Implementation not started.
